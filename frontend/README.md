# Frontend — Rota Viva

**Stack:** Vue 3, TypeScript, Vite, Pinia, Vue Router, Tailwind CSS.

Este frontend contém a **primeira interface demonstrativa**: dashboard, lista de centros e sugestões obtidas de dados **sintéticos no navegador**. Não está integrado ao backend.

```bash
npm install
npm run dev
npm run build
npm run test:domain
```

Antes de implementar operações de escrita, feche os contratos em `../docs/api-contract.md`. A lógica local é **apenas referência de simulação**; na integração, o servidor será responsável pelos saldos e reservas globais.
