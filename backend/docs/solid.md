# SOLID — Back-end Rota Viva

Aplique os cinco princípios SOLID em todo o código do back-end:

- **S:** responsabilidade única.
- **O:** aberto para extensão e fechado para modificação.
- **L:** substituição de Liskov.
- **I:** segregação de interfaces.
- **D:** inversão de dependência.

Respeite a estrutura definida em [clean-architecture.md](./clean-architecture.md). Combine SOLID com Clean Code, DRY, KISS e YAGNI, evitando abstrações desnecessárias e alterações fora do escopo solicitado.
